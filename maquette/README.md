# Maquette Agendo

Référence design statique (HTML, Tailwind via CDN, police Inter, couleurs indigo / violet). Ces fichiers ne font pas partie de l'application Next.js : ils restent consultables tels quels.

Ouvrir `index.html` dans un navigateur (une connexion internet charge la police et Tailwind).

Les générateurs Python du dossier `src/` écrivent les pages dans ce dossier (`/workspace/maquette/` en absolu dans les scripts).

GitHub Pages publie ce dossier via `.github/workflows/pages.yml`, à condition que la source Pages du dépôt soit **GitHub Actions** (Settings → Pages). L'adresse attendue est [https://carflowauto.github.io/agendo/](https://carflowauto.github.io/agendo/).
