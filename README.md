# Agendo

Maquette de l’app de prise de rendez-vous et de gestion de planning.

Ce dépôt contient la **référence design finale** (maquette HTML cliquable) : navigation, menus et écrans tels qu’ils devront apparaître dans le produit.

## Voir la maquette

- En local : ouvrir `index.html` dans un navigateur (une connexion internet est nécessaire pour la mise en forme).
- En ligne : [GitHub Pages](https://carflowauto.github.io/agendo/) (à activer une fois le dépôt publié).

## Contenu

Pages publiques : accueil, réservation, confirmation.  
Espace pro : planning, rendez-vous, prestations, clients, horaires & congés, synchronisation (Google Agenda et iCal / iPhone), paramètres.

## Prochaine étape

Développement de l’application en **Next.js** à partir de cette maquette.
